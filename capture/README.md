# 节点 B：双码流采集

子码流一直开着，只交给节点 C 做运动判断。主码流在触发之后才连续读取，帧率初值 5（每 0.2 秒一帧），运动结束后再读 3 秒。

| 文件 | 作用 |
| --- | --- |
| `streams.py` | 主码流窗口，以及读失败后 1 秒、2 秒、4 秒、上限 30 秒的等待 |

打开摄像头、保留最新一帧的线程在 `demo/run_camera.py`。那里默认是采用方案：空闲时不解码主码流。`--main-always` 是备用方案（主码流一直连着，运动检测用缩到 640×360 的副本）。

不要把子码流上的框和主码流上的框接成同一条轨迹。运行一天之后磁盘上不应出现 mp4、mkv、avi。
