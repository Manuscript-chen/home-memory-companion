# 节点 F：状态机

纯函数。输入是一条轨迹的点列、当前时间和主码流宽高。输出是 `placed`、`removed`、`occluded`、`conflict` 或 `unknown`。不读数据库，不调用检测器。

| 文件 | 作用 |
| --- | --- |
| `state_machine.py` | 边缘 8%，静止 0.05 画宽/秒，移动 0.15，放下需要 2.6 秒，丢失 1.5 秒，速度窗口 0.4 秒 |

`unknown` 不入库。同一轨迹、同一输出不写第二行。没有 30 分钟抑制。

断言在 `demo/run_demo.py`：中心停 3 秒是放下，只停 1.5 秒是未知，移出画面后是拿走，停在中心后消失是挡住。
