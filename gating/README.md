# 节点 C：运动门控

输入是子码流缩成的 640×360 图像。输出只有一个布尔值：这一刻要不要去读主码流。不输出物品名。

| 文件 | 作用 |
| --- | --- |
| `background.py` | 背景模型。采用 MOG2（history=500，varThreshold=16，detectShadows=False）。KNN 只在备用条件成立时换这一处 |
| `trigger.py` | 四条规则一起用：进入、退出滞回、冷却 2 秒、亮度跳变超过 30% 则冻结 10 秒 |

`demo/run_demo.py` 用假的面积序列检查连续 3 帧、冷却和亮度冻结。
